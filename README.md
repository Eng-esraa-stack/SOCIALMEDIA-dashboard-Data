## 🗂️ هيكل ملف البيانات (`متابعة_شكاوى_المواطنين_ولوحة_المؤشرات.xlsx`)

يتكون المصنف من **4 أوراق عمل (Sheets)** مترابطة:

1. **`لوحة المؤشرات`:** ملخص تنفيذي للمؤشرات الرقمية (KPIs) والجداول الإحصائية الداعمة للرسوم البيانية.
2. **`سجل الشكاوى`:** السجل الرئيسي للشكاوى، ومقسّم إلى مجموعات حقول:
   - **بيانات الشكوى والتصنيف:** كود الشكوى (`2026/001` إلخ)، تاريخ الشكوى، عنوان المنشور، نص الشكوى، المنطقة/المدينة، القطاع، طبيعة الحل المطلوب، درجة الأهمية، والجهة المختصة المقترحة.
   - **المتابعة وحالة الشكوى:** حالة الشكوى (`جديدة`، `تحت الإجراء`، `جاري الحل`، `تم الحل`، `حفظ/تعذر الحل`)، تاريخ الإحالة، الجهة المحال إليها، تاريخ الحل، مدة الاستجابة (يوم)، وعمر الشكوى المفتوحة (يوم).
   - **التواصل والتوثيق الميداني:** اسم صاحب الشكوى، وسيلة التواصل، رابط التعليق والمنشور، الباحث الراصد، وملاحظات المتابعة الميدانية.
   - **ضبط جودة البيانات:** مؤشر التكرار (`نعم`/`لا`)، اسم ملف صورة التعليق، وملاحظات التدقيق.
3. **`القوائم`:** القوائم المرجعية المنسدلة (حالات الشكوى، درجات الأهمية، القطاعات، المناطق، والباحثين).
4. **`ملاحظات`:** توثيق منهجية تنظيف البيانات ومعالجة التواريخ والتكرارات والمعادلات المستخدمة.

## ⚙️ ضوابط جودة البيانات ومنهجية التحديث

- **توحيد السجلات:** كل صف يمثل شكوى أو تعليقاً مستقلاً مع دمج النصوص الطويلة في خلية واحدة، وتوليد كود تلقائي (`2026/XXX`) عند إضافة أي شكوى جديدة.
- **تدقيق التواريخ:** تمت مراجعة وتصحيح التواريخ المعكوسة (يوم/شهر) وتوحيد السنوات لضمان دقة حساب **عمر الشكوى المفتوحة** و**مدة الاستجابة**.
- **إدارة التكرار:** تم وسم الشكاوى المتطابقة بـ `نعم` في عمود `مكررة؟` (4 شكاوى) للإبقاء على سجل الرصد الكامل دون فقدان بيانات التفاعل.
- **التكامل مع GIS:** يمكن تصدير شيت `سجل الشكاوى` بصيغة `CSV UTF-8` وربطه مباشرة بطبقة المناطق/المدن في **ArcGIS Dashboards** لعرض التوزيع المكاني وحالة الإنجاز لحظياً.
